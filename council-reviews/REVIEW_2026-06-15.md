## Engineering panel

### Architect

*"A repo whose whole religion is 'one source of truth' now keeps the same eight role blurbs in three files — and built a linter to make sure all three stay wrong together."*

**MED · medium** — Role prose is now triplicated
`scripts/lint_frontmatter.py:28-37` · `council/SKILL.md:36-67` · `PROMPT.md:21-53`
The linter hardcodes each role's full description as a substring to match, so changing any role's wording now requires editing three files in lockstep — the linter is a third canonical copy, not a guard against drift.

**LOW · quick-win** — Sync check is brittle by construction
`scripts/lint_frontmatter.py:43-46`
The "Experience" role already needs a special-cased `includes`/`include` fallback to pass; any future punctuation or wording tweak to a role will throw a false lint failure rather than catch a real one.

**LOW · —** — Skill catalog table is a fourth description site
`README.md:98-107`
Already labeled "summary; SKILL.md canonical," so low risk — but it's the fourth place the panel is described, and #1 above means tooling no longer protects it.

### Security reviewer

*"`agy plugin install .` runs whatever main says, and the README's selling point is that `git pull` pushes that to every machine at once. Bold."*

**LOW · quick-win** — Unpinned CI dependency
`.github/workflows/lint.yml:19`
`pip install PyYAML` with no version pin lets a future PyYAML release break CI on a commit that didn't touch Python.

**LOW · —** — Supply-chain posture unchanged (documented)
`README.md:80-84`
The symlink auto-update / `agy plugin install` execution risk is real but already disclosed with pin-by-commit mitigation; no new secrets — repo is markdown + a stdlib-only linter, confirmed by file audit.

### Performance, infra & scale

*"Caps came off in the name of thoroughness; on a real codebase the council will now happily write a novella and bill you for it."*

**HIGH · quick-win** — Uncapped findings = unbounded output cost
`council/SKILL.md:28` · `PROMPT.md:60`
`Provide all findings for each role` has no ceiling; on a large app this risks output-token truncation (~50+ findings, >8k tokens) and inflated per-run cost on usage-billed platforms. This was 06-14 action #1 and is still open.

**LOW · —** — Context cost still negligible
`council/SKILL.md`
SKILL.md grew to 104 lines this session; per-session load cost remains trivial. No action.

### Reliability (operator + QA)

*"There's a CI job, a test suite, and a version field — none of which would notice if the agy plugin shipped the wrong version or didn't load at all."*

**MED · quick-win** — Version drift between manifest and skill is unguarded
`plugin.json:3` · `council/SKILL.md:4`
Both read 1.2.0 today, but the sync check (`lint_frontmatter.py:6`) only compares role prose — nothing asserts the two version strings match, so the agy manifest will silently fall behind on the next SKILL bump. This is the ONE gate worth adding.

**MED · medium** — No test that the skill actually runs
`scripts/test_linter.py`
The suite exercises the linter's own branches, not whether `/council` executes or produces a well-formed report — a prompt regression (e.g. a broken output instruction) passes CI green. 06-14 action #3 is only half delivered.

**LOW · —** — agy path is unexercised
`README.md:60-73`
No machine or CI ever runs `agy plugin install .`; if its manifest schema is wrong (see Experience), nobody finds out until a user does.

### The Critic (no filter)

The infrastructure-to-content ratio, already backwards at 06-12, has now lapped itself: a 104-line markdown file is guarded by a linter that re-types the file's own contents as match strings, a CI workflow, a unit-test suite for the linter, an agy manifest nobody has run, and a versioning convention with no enforcement. The anti-drift mission is now generating drift — three copies of the role prose and two unsynchronized version numbers — which is a special kind of irony for a repo named after a panel of experts. And the headline feature of this session is making the robot tell jokes. None of it is wrong, exactly, but the council has spent another session grooming itself instead of judging anyone. The version string says 1.2.0; the number of external apps reviewed says 0. Fix the caps, wire the version gate, then close the laptop and run it on something that isn't itself.
